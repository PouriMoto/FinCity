# شهر ابزار مالی — ساختار پروژه

## همه‌چیز الان یکدست است

هر ۶ بازی حالا از یک معماری واحد استفاده می‌کنند: پوسته‌ی کاغذی/دست‌نویس (rough.js)، روایت با قلاب و تعلیق،
ساختار ماژولار `src/` + `tools/bundle.py`، و هیچ فایلی بلندتر از ~۳۵۰ خط. دیگر Archetype A/B جدا وجود ندارد —
همه یک الگو هستند، فقط بعضی‌ها ابزار محاسباتی (Chart.js) هم دارند و بعضی ندارند.

## نقشه‌ی کامل پوشه‌ها

## گردش‌کار (برای هر بازی، همیشه همینه)

1. ویرایش در `games/<slug>/src/` — نه در `index.html`.
2. `python3 tools/bundle.py <slug>` (یا `--all` برای همه).
3. اعتبارسنجی روی **`index.html` تولیدشده**: `node --check` + بررسی id ها + تعادل `<div>`/`<section>`.
4. اگر بازی جدیده، کارتش را در `dashboard.html` هم اضافه کن.

## معماری هر بازی

| فایل | نقش |
|---|---|
| `src/scenes.html` | فقط بدنه‌ی `<div class="app" data-title="...">` با صحنه‌ها |
| `src/NN-*.js` | منطق، به ترتیب حروف الفبا بارگذاری و به‌هم‌متصل می‌شوند (۰۱، ۰۲، ...) |
| `src/game-style.css` | فقط کلاس‌های اختصاصی همین بازی |
| `src/extra-cdn.txt` | فقط اگر بازی به کتابخانه‌ای جز rough.js نیاز دارد (مثلاً Chart.js) |

کلاس‌ها/توابعی که در ≥۲ بازی تکرار شدند، به `shared-src/` منتقل شدند: `char-intro-grid`/`char-card` (کارت
معرفی شخصیت)، `guess-choice-row` (دکمه‌ی حدسِ چندگزینه‌ای)، `tangle-*` (عدد قابل‌کشیدن). این قانون برای هر
اضافه‌ی بعدی هم برقرار است — دومین استفاده‌ی تکراری، سیگنالِ کافی برای استخراج به shared است، نه چهارمین.

## دو مکانیزم روایی که اضافه شدند

- **Tangle-lite** (برت ویکتور): عدد داخل خودِ جمله قابل‌کشیدنه — `compound-gold` و `inflation` (نرخ/مدت) و
  `race` (۴ نرخ بازده + مدت) ازش استفاده می‌کنن.
- **حلقه‌ی رشد/فرسایش به سبک Loopy** (نیکی کیس): یک دایره که هر «تیک» رشد/کوچک می‌شه — در `compound-gold` و
  `inflation`. هنوز ماژول مشترک نشده (فقط ۲ استفاده، با جزئیات کمی متفاوت)؛ در استفاده‌ی بعدی استخراجش کن.

## چرا این ساختار؟

- **هر بازی، پوشه‌ی مستقل خودش** — عکس، صدا، و منطق هر بازی جدا از بقیه است.
- **کد مشترک یک‌جا** — منطق فقط یک‌بار نوشته می‌شود.
- **آدرس‌دهی نسبی در همه‌جا** — هیچ URL کامل یا دامنه‌ای هاردکد نشده.
- **فایل‌های کوچک + اسکیمای داده‌محور** — هیچ فایلی بلندتر از ~۳۵۰ خط نیست، پس توسعه توسط هر AI یا
  توسعه‌دهنده‌ی دیگر بدون خواندن کل پروژه ممکن است.
- **bundle.py پل بین ماژولار و قابل‌پیش‌نمایش است** — منبع همیشه تکه‌تکه می‌ماند، ولی خروجی همیشه یک فایل
  خودکفا و قابل‌تست است.
