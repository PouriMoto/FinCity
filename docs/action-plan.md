- داشبورد + ۴ بازی ساخته و تست شدن (بهره مرکب، فرسایش تورم، مسابقه رشد سرمایه، بخر یا بفروش)
- داستان ویزارد هر ۴ بازی نوشته شده (`financial-city-stories.md`)
- تصمیم گرفته شد: شخصیت‌های مهدی‌یار، شهریار، نازی‌یار از کافینت‌یار قرض گرفته می‌شن برای هردو پروژه

## ۱. نقشه‌ی محله‌ها ↔ بازی‌ها ↔ شخصیت‌ها

| محله | بازی | شخصیت راوی | وضعیت |
|---|---|---|---|
| 🌾 مزرعه‌ی صبر | بهره مرکب + فرسایش تورم | مهدی‌یار | ✅ ساخته شده، داستان آماده — فقط تصویر لازمه |
| 🐎 اصطبل معاملات | مسابقه رشد سرمایه | شهریار | ✅ ساخته شده، داستان آماده — فقط تصویر لازمه |
| 🔭 برج رصد بازار | بخر یا بفروش | نازی‌یار | ✅ ساخته شده، داستان آماده — فقط تصویر لازمه |
| 🤝 میدان اعتماد کسب‌وکار (جدید) | الهام از Evolution of Trust | شهریار (چون به کسب‌وکار مربوطه) | 🔲 در انتظار طراحی |
| 🧠 موزه‌ی ذهن | سوگیری‌های رفتاری (لنگر، FOMO، زیان‌گریزی) | نازی‌یار یا مهدی‌یار | 🔲 بک‌لاگ |
| 🏭 کارخانه | جریان نقدی / قیمت‌گذاری کارآفرین | شهریار | 🔲 بک‌لاگ |
| 🌫️ جنگل سردرگمی | تشخیص کلاهبرداری مالی | نازی‌یار (اعتماد ↔ عدم‌اعتماد، تناسب موضوعی قوی) | 🔲 بک‌لاگ |
| 🏘️ محله‌ی املاک | رهن در برابر اجاره | شهریار | 🔲 بک‌لاگ |
| ☕ کافه | نشتی بودجه‌ی روزانه | مهدی‌یار | 🔲 بک‌لاگ |

## ۲. فازبندی پیشنهادی

### فاز ۱ — تکمیل چیزی که داریم (اولویت فوری)
هدف: ۴ بازی موجود از حالت «ابزار خشک» به «تجربه‌ی داستانی» تبدیل بشن، بدون نیاز به بازسازی کد.
- [ ] برای هر بازی، صفحات ویزارد داستان (که نوشتیم) به‌عنوان مقدمه قبل از ورود به ابزار اضافه بشه
- [ ] تصویرسازی: چون سبک هدف «ساده و دست‌ساز» است (نه انیمیشن)، می‌تونی از همون مهارت اسکچ‌نوت خودت استفاده کنی — دقیقاً سبک «آدمک چوبی ساده» نیکی کیس، نه چیز پیچیده
- [ ] یک استایل بصری واحد برای هر ۳ شخصیت مشخص بشه (خط ساده، تک‌رنگ + یک رنگ تاکیدی، شبیه چیزی که برای برند کافینت‌یار داری)

خروجی این فاز: ۴ بازی موجود، حالا با مقدمه‌ی داستانی

### فاز ۲ — بازی پنجم: میدان اعتماد کسب‌وکار
هدف: پیاده‌سازی نسخه‌ی الهام‌گرفته از Evolution of Trust با سناریوی کسب‌وکار ایرانی (نه سرباز جنگ جهانی)
- [ ] طراحی سناریو: دو مغازه‌دار/دو شریک تجاری، بازی تکرارشونده با ۳-۴ استراتژی (همیشه صادق، همیشه کلاه‌بردار، تلافی‌جو، بخشنده)
- [ ] نوشتن داستان ویزارد (به سبک همون جدول‌های قبلی)
- [ ] پیاده‌سازی به‌عنوان بازی پنجم در داشبورد

*(وقتی آماده بودی برای این فاز، بگو تا مکانیک دقیق + کد رو باهم بسازیم.)*

### فاز ۳ — گسترش محله‌ها (بک‌لاگ اولویت‌بندی‌شده)
پیشنهاد ترتیب بر اساس ارزش/سادگی ساخت:
1. **کافه (نشتی بودجه)** — ساده‌ترین از نظر فنی، ارتباط روزمره‌ی قوی
2. **موزه‌ی ذهن (سوگیری‌ها)** — محتوای کوتاه، قابل تبدیل به چند مینی‌گیم مجزا
3. **جنگل سردرگمی (کلاهبرداری)** — ارزش اجتماعی بالا، می‌تونه محتوای اینستاگرام پرتعامل بسازه
4. **کارخانه (کارآفرینی)** — به تجربه‌ی شخصی خودت نزدیک‌ترینه، ولی پیچیدگی طراحی بیشتر
5. **محله‌ی املاک** — نیاز به داده‌های واقعی بازار مسکن ایران، پیچیده‌تر برای درست از آب دراومدن

### فاز ۴ — یکپارچه‌سازی با استراتژی محتوای اینستاگرام
- هر بازی/محله‌ی جدید → یک پست/ریلز معرفی با کاراکترها
- quest board موجودت می‌تونه «تکمیل هر محله» رو به‌عنوان یک ماموریت XP تعریف کنه

## ۳. پروژه‌ی موازی: الهام از «گرگ اضطراب»

**نقش این پروژه:** آزمایشگاه جدا برای تست الگوهای داستان‌گویی تعاملی و رفتار کاربر — **نه بخشی از شهر ابزار مالی**، پس در فازبندی بالا وابستگی نداره و می‌تونه هر زمان که خواستی، موازی و بدون فشار پیش بره.

چیزهایی که از اونجا می‌تونی یاد بگیری و بعداً (اگه خواستی) به شهر ابزار مالی منتقل کنی:
- رابط چت‌مانند برای دیالوگ (به‌جای صفحات ویزارد ایستا)
- مکانیک «نوار انرژی/حس» که با انتخاب‌های کاربر تغییر می‌کنه
- الگوی پایان‌های چندگانه بر اساس مسیر انتخابی

هروقت خواستی روش کار کنیم، جدا صداش کن — قاطی برنامه‌ی اصلی نمی‌شه.
